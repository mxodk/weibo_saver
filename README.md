# 微博下载器

Android 微博图片和视频下载工具。在应用中粘贴一条微博链接，解析当前帖正文与媒体，预览后选择保存。

## 功能

- 展示、展开和复制正文；无法取得完整长文时给出提示。
- 预览图片与视频，支持图片缩放、左右切换、勾选和滑动选择。
- 全部保存或仅保存所选媒体；重复保存生成独立文件。
- 保存到默认相册目录，或通过系统选择本地文件夹。
- 显示保存进度，支持取消及失败项重试；同时运行一个保存批次。
- 切换应用、返回桌面或锁屏后继续保存；划掉应用后停止未完成任务，再次打开不自动续传。
- 外观默认跟随系统，也可选择浅色或深色。

## 使用

1. 打开应用，粘贴微博链接，点击“解析”。
2. 查看正文和媒体，调整需要保存的项目。
3. 点击“全部保存”或“保存所选”，在下载面板查看进度和失败项。

默认图片目录为 `Pictures/WeiboSaver/`，视频目录为 `Movies/WeiboSaver/`。可在设置中更改保存位置，新设置只影响之后发起的批次。

## 支持范围与限制

- 最低系统配置为 Android 12（API 31）；各系统版本与机型的兼容性仍在验证中。
- 当前源码准备版本为 `1.0.0`，尚未正式发布。
- 无需用户登录账号，自动取得临时访客会话；微博访问限制、网络变化或接口变更可能导致解析或下载失败。
- 只解析当前帖，不回退解析被转发帖；一次仅处理一条帖子链接。
- 图片使用微博接口可提供的高清资源，保存时不主动重压缩；不保证等同上传前原文件。
- Live Photo 仅支持静态图片预览与保存，不保存动态部分。
- 不包含多帖子批量导入、长期历史记录或中断后的自动续传；不同系统的后台与相册行为可能不同。

## 数据与权限

链接解析和保存请求由手机直接访问微博及媒体服务，不依赖本项目服务器，不读取浏览器登录状态。临时访客凭据仅在内存中使用。应用保存外观、目录设置、首次操作提示标记及清理未完成文件所需的本地记录；不接入统计或自动崩溃上报。

联网用于解析与下载，前台服务和通知用于保存进度，短时 CPU 锁用于传输；自选文件夹通过系统授权访问，不申请整个相册的读取权限。拒绝通知授权后仍可在应用内查看保存进度。
